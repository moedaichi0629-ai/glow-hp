# GLOW｜リラクゼーションサロンのWebページ

店舗紹介・サービス・アクセス・電話問い合わせへの導線をまとめた、サロン向けの静的Webページです。

[ポートフォリオ](https://moedaichi0629-ai.github.io/)

## 主な機能

- 店舗紹介・サービス内容・アクセスの表示
- Googleマップの埋め込みと外部マップへのリンク
- 電話リンクとスマートフォン向けの固定問い合わせボタン
- PC・スマートフォンの画面幅に合わせた表示

## 使用技術

HTML / CSS / Google Fonts。ページとスタイルは `index.html` に含まれています。

## 表示方法

リポジトリを取得し、`index.html` をブラウザで開きます。フォント・地図の読み込みにはインターネット接続が必要です。

## 実装範囲

電話問い合わせへの導線を備えた静的ページです。オンライン予約の受付処理・管理画面は実装していません。
店舗との契約・納品・公式サイトとしての承認状況は、このリポジトリからは確認できません。
